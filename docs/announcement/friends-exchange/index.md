向站长邮箱【849758831@qq.com】发送申请邮件，主题注明「友情链接」，附上以下信息：

1. 站点名称；

1. 优先收录个人博客 / 独立站点，主题不限（技术、生活、摄影等均可）；
2. 站点可正常访问，且近半年内有更新（长期停更的站点暂不收录）；
3. 内容合法合规，不含色情、赌博、广告营销等违规内容；
4. 原则上不收录商业站点与导航类站点；
5. 已收录站点如出现侵权、违规内容或长期无法访问，本站有权随时撤下友链，不再另行通知。

### （二）回复时限

1. 提交申请后 1～3 个工作日内回复，谢谢支持！
